Notas operativas

Olimpo Control — Activación Loyverse
Jose debe proveer su token de API Loyverse. Una vez que lo tenga:
1. Abre la app · entra como dueño · ve a Avanzado.
2. Ingresa el token en "Conectar Loyverse" · guarda.
3. Reinicia node server.js en el servidor.
Sin reinicio, el token queda guardado pero inactivo.
EmailJS — Recuperación de acceso
Crear cuenta en EmailJS (200 envíos/mes gratis). Llenar EMAILJS_CONFIG en email-recovery.js de cada proyecto.
Mientras no esté configurado, el código de recuperación aparece en pantalla en vez de enviarse por correo.
Master admin — Mi protocolo
Si un cliente pierde acceso y no tiene correo registrado:
1. Abrir la app del cliente en mi dispositivo.
2. Avanzado → "Cambiar correo" → ingresar OLIMPO-MAESTRO-2026 (o el código del proyecto).
3. Registrar el correo del cliente → el flujo encadena solo al reseteo de PIN.
El server-side nuclear (777) solo si lo anterior falla — conectarse al servidor y hacer POST directo.
